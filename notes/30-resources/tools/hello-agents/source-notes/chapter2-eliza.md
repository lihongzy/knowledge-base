# 第二章：ELIZA 规则型聊天机器人

源码：[ELIZA.py](../code/chapter2/ELIZA.py)

## 学习目标

理解早期聊天机器人如何使用固定规则处理用户输入，以及这种方法与大语言模型的区别。

## ELIZA 是什么

ELIZA 是一个早期的对话程序。它不理解语言的真实含义，也不调用大语言模型；它根据用户输入是否符合预设句式，选择对应的回复模板。

本章代码将它设计成一个心理咨询师风格的聊天机器人。

## 程序流程

```text
用户输入
-> 使用正则表达式依次匹配规则
-> 提取规则中的关键内容
-> 转换第一人称和第二人称代词
-> 随机选择回复模板并填入内容
-> 输出回复
```

## 核心知识点

### 规则库

`rules` 将正则表达式和回复模板关联起来。

```python
r"I need (.*)"
```

该规则用于匹配以 `I need` 开头的输入。`(.*)` 是捕获组，表示提取后面的任意文本。

例如输入 `I need a vacation`，捕获组的内容是 `a vacation`。

### 正则表达式与捕获组

`re.search()` 用于判断输入是否符合某条规则，`match.group(1)` 用于取得第一个捕获组。

```python
match = re.search(pattern, user_input, re.IGNORECASE)
captured_group = match.group(1)
```

`re.IGNORECASE` 使大小写不影响匹配结果。

### 回复模板与随机选择

每条规则对应多条回复。`random.choice()` 随机选择其中一条，`{0}` 会被捕获内容替换。

```python
response = random.choice(responses).format(swapped_group)
```

因此，同一句输入可能得到不同的回复。

### 代词转换

`swap_pronouns()` 将用户表达中的第一人称转换为面向用户的第二人称。

例如输入 `I need my mother's help`，提取内容中的 `my` 会转换为 `your`，让回复保持对话视角。

### 兜底规则

最后的 `r".*"` 可以匹配任意输入。当其他具体规则都没有匹配时，程序会返回通用回复，例如 `Please tell me more.`。

## 与第一章 Agent 的区别

ELIZA 的回答来自人工预先写好的规则和模板，不能根据上下文推理，也不能调用工具获取新信息。

第一章的旅行助手由大语言模型决定行动，并能调用天气和景点搜索工具。ELIZA 展示的是智能对话程序的早期实现方式；第一章展示的是基于大语言模型和工具调用的 Agent。

## 我的理解

ELIZA 看起来能够对话，实际是在识别句式后套用预设文本。它说明了对话体验可以由规则构建，但规则覆盖范围有限。大语言模型使 Agent 能够理解更丰富的表达、结合上下文，并根据任务选择工具。
