# Domain Docs

Engineering skills use the repository as a single domain context.

## Before exploring

- Read root `CONTEXT.md` when it exists.
- Read relevant decisions under `docs/adr/` when they exist.
- Proceed without comment when either location is absent.

## Layout

```text
/
|- CONTEXT.md
|- docs/
|  `- adr/
`- notes/
```

`/domain-modeling` creates domain vocabulary and architectural decisions when they are needed. Use terms defined in `CONTEXT.md`, and explicitly flag any conflict with an existing ADR.
